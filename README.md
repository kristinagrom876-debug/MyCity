 Сначала я сделала слой с данными, а потом написала ViewModel, чтобы управлять состоянием экранов.
 Для телефона я сделала обычную навигацию по трем экранам: список категорий, список мест и подробная информация с фото.
 Я поняла, что если экран широкий, то приложение автоматически делит экран на две колонки: слева категории, 
 а справа места. А если экран узкий, то оно работает как обычное приложение с переключением экранов. Кнопку «Назад» я тоже настроила так, чтобы она 
 работала по-разному в зависимости от размера экрана.
